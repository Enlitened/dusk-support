# Dusk — site, support and privacy

The public pages for Dusk: Dark Mode for Safari, on iPhone, iPad and Mac. Published with GitHub Pages from `main`.

- Landing page — <https://enlitened.github.io/dusk-support/> (the App Store listing's Marketing URL)
- Support — <https://enlitened.github.io/dusk-support/support.html>
- Privacy policy — <https://enlitened.github.io/dusk-support/privacy.html>

All three URLs are the ones filed in App Store Connect. The source of truth is the app repository's `site/`
folder; edit there first, then bring the change across. Once the listing is live, replace "Coming to the App
Store" in `index.html` with the store link.
